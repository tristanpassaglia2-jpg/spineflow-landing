SPINEFLOW · PROYECTO MULTIARCHIVO LISTO PARA VERCEL

Qué incluye
- index.html principal
- assets/styles.css
- assets/data.js
- assets/app.js
- assets/images/valen.png
- pages/ por módulo
- pages/rutinas/ por rutina o etapa
- login.html
- vercel.json

Cómo subirlo a Vercel
1. Entrá a Vercel.
2. Elegí “Add New Project”.
3. Arrastrá esta carpeta o este zip.
4. Framework preset: Other / Static.
5. Build command: dejar vacío.
6. Output directory: dejar vacío.
7. Deploy.

Compatibilidad
- Proyecto estático puro: HTML + CSS + JS.
- No necesita Node, build ni dependencias.
- vercel.json ya incluye cleanUrls y cache para assets.

Qué falta para producción real
- Pagos: Stripe o Mercado Pago.
- Autenticación: Supabase o Firebase.
- Analytics: GA4, Meta Pixel o eventos custom.
- CRM / captación: formularios, WhatsApp o email automation.
